### Voicebox TTS Engine Architecture

Voicebox uses a modular TTS backend with multiple engine implementations, including Qwen3-TTS, LuxTTS, and Chatterbox variants. The system supports multiple languages and provides a REST API for generation. The architecture includes a thread-safe engine registry and model management features.

- TTSBackend protocol supports seven engine implementations including Qwen3-TTS, LuxTTS, and Chatterbox variants
- Backend exposes REST API for TTS generation with HTTP endpoint at localhost:17493
- Model registry and thread-safe engine registry are implemented in backend/backends/__init__.py
- Frontend communicates with backend via HTTP and uses TypeScript API types

Source : https://raw.githubusercontent.com/jamiepine/voicebox/main/docs/PROJECT_STATUS.md ; niveau 2.
