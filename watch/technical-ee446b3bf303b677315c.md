## Capacités documentées

- Permet de configurer un serveur SMTP pour tester les envois d'e-mails.
- Fournit une interface web pour visualiser les messages envoyés.
- Permet de libérer les messages vers un serveur SMTP réel.
- Possède une API HTTP pour gérer les messages envoyés.

## Usages documentés

- Configurer l'application pour utiliser MailHog comme serveur SMTP.
- Accéder à l'interface web pour consulter les messages.
- Utiliser l'API HTTP pour gérer les messages.
- Libérer les messages vers un serveur SMTP réel si nécessaire.

## Limites

- Requiert une configuration SMTP correcte pour fonctionner.
- Stockage en mémoire par défaut, pas de sauvegarde persistante.
- Nécessite une installation ou un conteneur Docker pour exécuter le serveur.
