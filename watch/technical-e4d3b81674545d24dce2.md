## Capacités documentées

- Génère des codes QR 2D et d'autres types de codes-barres.
- Supporte les modes d'encodage numérique, alphanumérique, kanji et byte.
- Optimise la compression des données pour réduire la taille du code QR.
- Génère des images PNG, SVG ou des chaînes UTF-8.
- Possibilité de spécifier le niveau de correction d'erreur.
- Adaptable à différents environnements (serveur, client, React Native).

## Usages documentés

- npm install --save qrcode
- npm install -g qrcode
- qrcode "some text"
- qrcode -o out.png "some text"

## Limites

- Requiert un environnement Node.js ou un module compatible.
- Ne prend pas en charge les caractères multibytés sans conversion spécifique.
- Nécessite une gestion manuelle pour les modes kanji avancés.
