## Capacités documentées

## Usages documentés

- Installer Kimi Code CLI via script.
- Ouvrir un terminal et exécuter `kimi` pour détecter les données existantes.
- Exécuter `kimi migrate` pour migrer les données.
- Se reconnecter via `/login` pour autoriser les serveurs MCP.
- Désinstaller l'ancien CLI après migration.
