### FreeLLMAPI : Gestion centralisée des API LLM gratuits

FreeLLMAPI est un outil qui permet de gérer des API LLM gratuits via un point d'accès unique. Il combine des modèles de différents fournisseurs et optimise l'utilisation des quotas.

- Gère jusqu'à 7,4 milliards de tokens par mois.
- Intègre 34 fournisseurs et 635 endpoints gratuits.
- Route automatiquement les requêtes vers les modèles disponibles.
- Synchronise automatiquement les catalogues de modèles.
- Chiffre les clés des fournisseurs.
- Supporte les API OpenAI et Anthropic.
- Permet la fusion de réponses de plusieurs modèles.
- Fournit une interface de gestion et d'analyse.
- Utilisable sur Windows, macOS, Linux et ARM.
- Fournit un client MCP pour ChatGPT et autres outils.

Source : https://raw.githubusercontent.com/tashfeenahmed/freellmapi/main/README.ru.md ; niveau 2.

- FreeLLMAPI route vers les modèles d'IA gratuits disponibles.

### FreeLLMAPI : Architecture et fonctionnalités

FreeLLMAPI est un gateway OpenAI-compatible permettant d'utiliser des modèles gratuits via un token. Il gère les limites de débit et les échecs de manière dynamique.

- Permet d'utiliser des modèles gratuits via un token unique.
- Gère les limites de débit et les échecs avec un système de routage.
- Utilise un ledger en mémoire pour suivre les quotas.
- Fait tomber en mode dégradé quand les quotas sont atteints.
