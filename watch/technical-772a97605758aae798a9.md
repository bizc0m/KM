## Capacités documentées

- mailcat permet de trouver des adresses emails à partir d'un nom d'utilisateur.
- L'outil supporte plus de 150 fournisseurs d'email.
- mailcat utilise des méthodes comme SMTP, API ou récupération de données.
- Il peut être utilisé via la ligne de commande avec des arguments ou un fichier de noms.

## Usages documentés

- mailcat username
- python -m mailcat username
- mailcat --tor username
- mailcat --file usernames.txt

## Limites

- Nécessite un proxy ou Tor pour les vérifications SMTP.
- Certains fournisseurs nécessitent des bibliothèques spécifiques pour les tests.
- Les vérifications SMTP peuvent être bloquées par les fournisseurs.
- Les tests via Chromium nécessitent des bibliothèques système supplémentaires.
