### Problème d'intégration de Widevine CDM dans CloakBrowser sous Docker/Xvfb

Le problème d'absence de Widevine CDM dans CloakBrowser sous Docker/Xvfb est résolu en sideloadant le répertoire WidevineCdm depuis une installation de Chrome et en pré-initialisant le fichier de configuration.

- Le script de vérification de l'EME API montre que le support de Widevine est faux dans CloakBrowser sous Docker/Xvfb.
- Le répertoire WidevineCdm doit être copié depuis une installation de Chrome vers le répertoire de CloakBrowser.
- La création préalable du fichier de configuration Widevine permet à CloakBrowser de détecter le CDM dès la première utilisation.
- La solution a été testée avec succès sous Docker/Xvfb et permet la lecture de flux vidéo DRM.
