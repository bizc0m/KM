## Resume court

Right Click Prompt se presente comme une bibliotheque de prompts accessible rapidement depuis le clic droit, avec sauvegarde, organisation et partage de prompts.

## Usage KM

- Evaluer l'interet pour reutiliser des prompts courts dans les workflows navigateur.
- Comparer avec snippets locaux, TextExpander, Raycast, Obsidian, NotePlan et raccourcis systeme.
- Verifier si l'outil stocke les prompts localement ou dans un service distant avant tout usage avec contexte projet.

## Risque d'abus possible

- `sensible` : une bibliotheque de prompts peut stocker secrets, contexte client, instructions internes ou donnees personnelles si elle est utilisee sans hygiene.
- Risque d'injection indirecte si des prompts partages sont executes sans relecture.
- Pas de classification `#ROUGE` : l'item n'est pas un outil offensif directement abusable d'apres la source publique consultee.
