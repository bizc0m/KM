## Classification

`sensible`

Raison : outil d'analyse de code pouvant traiter des depots prives, de la logique metier, des secrets accidentels ou de la propriete intellectuelle. Pas de capacite offensive directe identifiee, donc classement rouge non retenu.

- Tester sur depot public ou sandbox sans secrets.
- Exclure `.env`, credentials, dumps, logs et donnees client avant indexation.
- Verifier le mode de stockage du graphe avant usage sur code prive.
