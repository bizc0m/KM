## Capacités documentées

- Implémente une technique FFT pour l'enregistrement d'images.
- Supporte la translation, la rotation et la mise à l'échelle.
- Utilise NumPy et Scipy comme dépendances.
- Développement actif arrêté, version dernière 2025.1.1.

## Usages documentés

- Installer via pip install imreg.
- Utiliser la fonction similarity pour aligner des images.
- Utiliser la fonction translation pour détecter le décalage.
- Afficher les résultats avec imshow.

## Limites

- Ne supporte plus Python 3.9.
- Nécessite NumPy 2.1.3 et Scipy 1.14.1.
- Pas de support pour Python 3.8.
- Développement arrêté, pas de mise à jour future.
