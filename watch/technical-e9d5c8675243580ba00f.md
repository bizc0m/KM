## Capacités documentées

- Fournit des couches de canaux pour Django utilisant Redis comme stockage.
- Deux implémentations disponibles : RedisChannelLayer et RedisPubSubChannelLayer.
- Supporte des configurations mono serveur et shardées.
- Testé avec Python 3.10 à 3.14 et différentes versions de redis-py.
- Permet la configuration de la couche de canaux via des paramètres dans les paramètres Django.
- Possibilité d'encryptage symétrique des messages.
- Utilisation de msgpack ou JSON comme format de sérialisation.
- Possibilité de personnaliser les sérialiseurs.
- Requiert un serveur Redis >= 5.0.
- Permet la gestion des événements de déconnexion/reconnexion.
- Utilise des commandes Redis spécifiques selon l'implémentation.
- Possibilité de connecter via UNIX domain socket.
- Configuration de la capacité des canaux et des groupes.
- Gestion de l'expiration des messages et des groupes.
