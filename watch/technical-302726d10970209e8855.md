## Capacités documentées

- CUAWright permet aux modèles de codage d'automatiser des navigateurs et des applications de bureau.
- Il intègre des outils pour exécuter des tâches web et desktop dans un environnement Ubuntu.
- CUAWright permet de générer des scripts réutilisables pour des tâches web.
- Il améliore les performances des agents web sur des benchmarks comme OSWorld-V2 et Online-Mind2Web.

## Usages documentés

- cuawright web pour les tâches web
- cuawright desktop pour les tâches desktop
- pip install -e . pour l'installation

## Limites

- Requiert Python 3.10+
- Dépend de Chromium via Playwright
- Nécessite une clé API pour les backends
