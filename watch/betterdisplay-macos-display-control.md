## Resume court

BetterDisplay est un utilitaire macOS pour le controle avance des ecrans : scaling HiDPI, luminosite, HDR/XDR, ecrans virtuels, DDC, extra dimming, PIP/streaming et EDID override.

## Usage KM

- Evaluer l'outil pour les setups multi-ecrans M2/M5, demos, captures, tests UI et workflows agents desktop.
- Comparer avec Rectangle, WhichSpace, reglages macOS, DisplayBuddy et scripts de layout.
- Verifier les permissions macOS necessaires avant integration dans un workflow automatise.

## Risque d'abus possible

- `sensible` : un outil de controle ecran peut affecter captures, streaming, ecrans virtuels et visibilite de donnees locales.
- Risque operationnel : mauvais profil d'affichage, EDID override ou controle DDC pouvant perturber un setup de travail.
