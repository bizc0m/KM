# Fiche KM actionnable

## Type
Prompt KM

## Tags
km, fiche, action

## Objectif
Transformer une fiche brute en fiche KM courte, sourcee et actionnable.

## Prompt
Lis la fiche fournie. Garde uniquement la fonction, les sources, les signaux utiles, les risques et les actions suivantes. Ne duplique pas les informations. Ne rajoute pas de contenu non source.
