# Triage source veille

## Type
Prompt veille

## Tags
veille, source, triage

## Objectif
Qualifier un signal RSS, Twitter, Reddit ou GitHub avant creation de fiche.

## Prompt
Classe le signal en garder, ignorer, fusionner ou verifier. Identifie la source primaire, l'URL finale, le risque d'abus, la fonction concrete et le prochain geste KM.
