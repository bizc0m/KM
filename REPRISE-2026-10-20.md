# Consolidation du 20 octobre 2026

## Règles appliquées

- Collecte NotePlan Calendar uniquement ; contenu technique public uniquement.
- Palette historique conservée dans km.colors.json. La proposition d'ontologie v2 reste hors production.
- Un titre court, un intérêt concret, les mots-clés précis ; pas de répétition nature/domaine/mot-clé dans la carte.
- Toutes les sources restent accessibles dans le détail, sans plafond de huit. Les rôles distinguent dépôt principal, site officiel explicite, publication d'origine, documentation et référence secondaire.
- Un dépôt cité dans une liste ne devient pas automatiquement l'identité de la fiche. Les URL de documentation ne deviennent pas des sites officiels.
- Fusion uniquement sur identité de dépôt établie ; sauvegardes privées, conservation des sources, réaffectation de l'état de collecte et redirection des anciens identifiants.
- Les descriptions absentes restent absentes plutôt que remplacées par du texte générique inventé.
- L'automatisation réapplique les qualifications issues des pages primaires puis les corrections vérifiées, avant et après la collecte. Elle produit un rapport de qualité.

## État contrôlé

Le snapshot public contient 513 fiches et 2 250 références de sources. Onze doublons confirmés ont été fusionnés sur le M2 avec sauvegarde. Aucun groupe de doublons parmi les identités de dépôt établies ne subsiste ; les identités non établies restent à examiner.

172 fiches ont été requalifiées avec les analyses locales déjà enregistrées de leur propre page primaire. Il s'agit d'analyses automatiques, pas d'une validation humaine. Quatre corrections ciblées ont été vérifiées sur les dépôts primaires : MiniSim, Whisper, Agent Skills et camofox-browser.

Le rapport public/quality.json recense les défauts restants, avec critères qui se recoupent : 173 intérêts absents, 48 fiches sans mots-clés, 56 domaines non qualifiés, 23 identités principales non établies et 465 natures non qualifiées. Ces nombres ne signifient pas que les autres contenus ont tous été vérifiés manuellement.

Les exports publics sont filtrés séparément des données privées du M2. Les caches et les sauvegardes NotePlan restent hors Git. Le snapshot public ne remplace jamais les fichiers de travail du M2.

## Vérification et exploitation

- npm run km:technical:test : tests de politique, exploration, classement, mots-clés, identité, sources, corrections et détail.
- node scripts/km-verify-placement.mjs : cohérence de placement des fiches générées.
- node scripts/km-quality-report.mjs : rapport de qualification du snapshot public.
- L'agent launchd existant com.bizc0m.km-technical-pipeline exécute scripts/km-technical-run.mjs sur le M2.
