# NightCrawl

NightCrawl / Night Intel is a living cultural radar for nightlife signals, DJ dates, city nodes, and transmission bots.

Mission:

MAKE THE INVISIBLE VISIBLE.

Tagline:

Render the chaos legible.

## Contents

- `NIGHT_INTEL_PROTOCOL.md` - global propagation protocol.
- `NIGHTCRAWL_SYNTHESIS.md` - product synthesis and free architecture.
- `BOT_TELEGRAM_DISCORD_SPEC.md` - Telegram and Discord bot spec.
- `nightcrawl-dashboard.html` - static experimental dashboard.
- `nightcrawl-bot.html` - bot/transmission interface with NightLife design.
- `nightcrawl-scan.html` - scan/radar interface for events and city signals.
