# Présentation des fiches

Trois lignes opérationnelles : Fonction · / Avantages · / Gain ·. Chaque ligne contient 3 à 12 mots et une information distincte documentée. Pas de bénéfice inventé ; une information absente est indiquée « Non établi par la source ».

Le M2 convertit les fiches publiables existantes avec le LLM local ; les anciennes versions sont sauvegardées dans Library/Application Support/KM/backups. Une réponse invalide conserve le texte existant et passe en revue. Une fiche déjà convertie est ignorée. Le rapport interests-progress.json compte total, selected, done et review. La reconstruction se fait après la première fiche puis toutes les dix fiches. Les cycles suivants reprennent les fiches restantes.

Les nouvelles fiches utilisent le même prompt. Jusqu’à deux images explicitement identifiées comme capture, aperçu ou démo dans le README ou le site sont référencées avec leur origine. Logos, badges et avatars sont exclus. Il s’agit d’images existantes, pas d’une prise automatique de capture de toutes les pages. L’absence d’image ne bloque pas la fiche. Les images restent hébergées par leur source et peuvent devenir indisponibles.
