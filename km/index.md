# KM Index

## Role

Index des fiches KM creees via `#km`.

## Fiches

| Appel | Fichier | Type | Tags | Statut |
| --- | --- | --- | --- | --- |
| `km:index` | `index.md` | index | km, index | actif |

## Regles fiche `#km`

Chaque fiche doit contenir :

- type ;
- tags ;
- relations ;
- resume ;
- source ;
- statut de deduplication ;
- historique.
